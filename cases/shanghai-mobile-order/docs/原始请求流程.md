# 3. 调用 /cardOrder/card.submit.contract 选择套餐并绑定orderId
# 4. 调用 /cardOrder/card.order.information.update 存储用户信息 这一步如果用户已经下过单会返回错误
# 获取订单确认页面，如下url
https://www.sh.10086.cn/emall/static/h5/card/card_orderconfirm.html?orderId=订单id
# 5. 调用 /cardOrder/card.order.submit 完成订单提交
