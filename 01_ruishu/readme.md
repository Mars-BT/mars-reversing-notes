# 识别
显著特征是cookies里会包含2个键值对，通常以S和T结尾。

## 瑞数3
特征：T键值对应开头值为3
示例网站：aHR0cHM6Ly93d3cuY2RlLm9yZy5jbi9tYWluL25ld3MvbGlzdHBhZ2UvM2NjNDViMzk2NDk3YjU5ODM0MWNlM2FmMDAwNDkwZTU=

## 瑞数4
特征：T键值对应开头值为4

## 瑞数5
特征：T键值对应开头值为5

## 瑞数6
特征：T键值对应开头值为6
示例网站：aHR0cHM6Ly93d3cubmhjLmdvdi5jbi93ancvZ2Z4d2pqL2xpc3Quc2h0bWw=

## VMP版本
特征：一样会有S和T键值对，但是开头不是数字
示例网站：aHR0cHM6Ly9jcmVkaXQuY3VzdG9tcy5nb3YuY24vY2NwcHdlYnNlcnZlci9wYWdlcy9jY3BwL2h0bWwvY2NwcGluZGV4Lmh0bWw=
